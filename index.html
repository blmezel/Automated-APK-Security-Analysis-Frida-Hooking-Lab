Projenin Temel Amacı

Bu projenin ana amacı, Android ekosistemindeki zafiyet barındıran uygulamaların hem kaynak kod seviyesinde (Statik) hem de bellek katmanında (Dinamik) güvenlik denetimlerini otomatize etmektir. "Önce anla, sonra güvenli kodla" felsefesini benimseyerek, potansiyel saldırı yüzeylerini minimuma indirmek hedeflenmiştir.

Güvenlik Modülleri

CLI Güvenlik & Risk Motoru

Hedef APK'nın Manifest dosyasını AST seviyesinde ayrıştırır, zafiyetli bileşenlere göre 0-100 arası matematiksel Risk Skoru üretir.

Runtime Memory Hooking

Uygulamanın JVM/Dalvik belleğine enjekte edilen JavaScript payload'ları ile SSL Pinning ve Root tespiti duvarlarını aşar.

Vaultwarden Vize Entegrasyonu

Capstone Engine (x86_64) Disassembler

Vize projesinin Capstone Motoru, src/vize_disassembler.py modülü olarak entegre edildi. Native NDK *.so dosyalarındaki Hex/Opcode bayt dizilimlerini doğrudan Assembly diline geri çevirir.

> Input Hex: b834120000904883ec08

0x1000: mov eax, 0x1234

0x1005: nop

0x1006: sub rsp, 8
